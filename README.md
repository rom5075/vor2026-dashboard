# VOR 2026 — карта работ команды

Интерактивный дашборд (план v14): кто на каких доработках, календарная карта июль–декабрь 2026, линия «сегодня» и отдельная матрица сроков по трём версиям плана.

**Сайт:** https://rom5075.github.io/vor2026-dashboard/

**Дедлайны:** https://rom5075.github.io/vor2026-dashboard/deadlines.html

## Как обновить и опубликовать

**Готово = запушено.** Локальные правки сами на https://rom5075.github.io/vor2026-dashboard/ **не попадут**. Без `push` → Actions → Pages страница для всех остаётся старой.

1. Правите **исходник**: `VOR2026_team_map_v14_3.html` (и/или `index.html`).
2. Сразу публикуйте одной командой (предпочтительно):

```bash
./publish.sh "краткое описание изменений"
```

Скрипт синхронизирует `index.html` из исходника, коммитит и пушит в `main`.

Вручную то же самое:

```bash
git add VOR2026_team_map_v14_3.html index.html
git commit -m "Update dashboard"
git push origin main
```

3. GitHub Actions сам соберёт сайт и зальёт на Pages (1–2 минуты).  
   Статус: вкладка **Actions** в репозитории.

**Для AI-агентов:** после любой правки UI/данных этого дашборда **обязательно** запускать `./publish.sh "…"` в том же ходе работы, если пользователь не сказал «только локально». Не ждать отдельной просьбы «запушь».

## Что деплоится

| Файл | Роль |
|------|------|
| `VOR2026_team_map_v14_3.html` | **Источник правды** — правьте его |
| `index.html` | Локальная копия для превью (обновляется скриптом `publish.sh`) |
| `deadlines.html` | Отдельная страница трёх Prod-дедлайнов по каждой доработке |
| `VOR2026_DEADLINES_MATRIX.md` | Проверяемый источник дат и пометок страницы дедлайнов |
| `scripts/build_site.sh` | Собирает полный статический каталог для Pages |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | PWA: установка на домашний экран и офлайн-режим |
| `.github/workflows/deploy-pages.yml` | Пайплайн: push → Pages |

При правке задач/дат обновляйте `meta.updated` в `DATA` (в шапке показывается как «данные от»).

Пайплайн запускает `scripts/build_site.sh`, кладёт основную страницу в `_site/index.html`, страницу сроков в `_site/deadlines.html` и публикует каталог через GitHub Pages (Actions).

## Локальный просмотр

Откройте `VOR2026_team_map_v14_3.html`, `index.html` или `deadlines.html` в браузере (двойной клик или Live Server).
